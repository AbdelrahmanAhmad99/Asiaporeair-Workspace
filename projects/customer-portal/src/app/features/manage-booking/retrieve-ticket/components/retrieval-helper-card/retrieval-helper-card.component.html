Which reference do I use?

Booking Reference vs Ticket Number explained

  • PNR
    Booking Reference A 6-character alphanumeric code (e.g. QR7K2M). Use this on the Retrieve Booking page to access all passengers associated with a reservation.
  • E-TKT
    Ticket Reference A unique 6–13 character code (e.g. 0172344567890). This is your individual electronic ticket and is found on your e-ticket confirmation email — one per passenger per flight segment.
